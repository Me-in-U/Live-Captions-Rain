# Screenshots

Screenshots for README and release pages should live under:

```text
docs/assets/screenshots
```

Current captures:

- `settings.png` - main settings window with the built-in demo visible. The local settings path is redacted.
- `demo-preview.png` - cropped built-in demo preview that shows falling words and window-top stacking without exposing the desktop.

Recommended future captures:

- `overlay-floor.png` - words falling and piling on the screen floor with a neutral desktop.
- `overlay-window-stack.png` - words stacking on a visible desktop window top with private content hidden.
- `tray-menu.png` - tray menu with common toggles.

Do not include screenshots that expose private caption text, account names, tokens, private chat messages, or unrelated personal data.

If a screenshot is only for local QA, keep it under `artifacts\verification` instead of `docs`.
